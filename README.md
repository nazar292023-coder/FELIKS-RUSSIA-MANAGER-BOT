# FELIKS RUSSIA | Manager Bot

Telegram-бот для заявок в медиа-команду и службы поддержки.

## Функции
- Главное меню и ссылки на форум/Telegram-канал.
- Заявка на медиа: канал, подписчики, просмотры, ссылки на 3 видео.
- Одобрение/отказ администрацией с уведомлением пользователя.
- При одобрении автоматически присваивается статус `🎬 Медиа`.
- Проверка статуса пользователя.
- Поддержка через ИИ (если задан OPENAI_API_KEY) и администрацию.
- История обращений, лимит 3 обращения в день.
- Админ-панель: открыть/закрыть набор, статистика, последние заявки и обращения.
- SQLite для хранения данных.

## Настройка
1. Создайте бота через @BotFather и скопируйте токен.
2. Узнайте свой Telegram ID через @userinfobot.
3. На хостинге добавьте переменные окружения:
   - `BOT_TOKEN` — токен бота.
   - `ADMIN_IDS` — ваш Telegram ID. Несколько ID указываются через запятую.
   - `OPENAI_API_KEY` — необязательно, для ответов ИИ.
   - `OPENAI_MODEL` — необязательно, по умолчанию `gpt-4o-mini`.
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите: `python bot.py`

## Важно про хранение базы
Для постоянного сохранения SQLite-файла нужен постоянный диск/volume на хостинге. Если хостинг удаляет локальные файлы при перезапуске или пересборке, история и заявки могут потеряться. Укажите `DATABASE_PATH` на путь постоянного диска, если он предоставлен хостингом.

## Безопасность
Не публикуйте токен бота в GitHub и не отправляйте его в чаты. Добавляйте токен только в секретные переменные хостинга.
